# GitHub Sponsors & Community Pack — Installation

Target repository: https://github.com/JamieChristian22/Business-Analyst-Portfolio2

## Contents

- `.github/FUNDING.yml` — enables the GitHub Sponsors funding link (when repository sponsorship display is enabled).
- `.github/ISSUE_TEMPLATE/bug_report.yml` — bug-report issue form.
- `.github/ISSUE_TEMPLATE/feature_request.yml` — enhancement request form.
- `CONTRIBUTING.md` — contribution instructions.
- `CODE_OF_CONDUCT.md` — community standards.
- `SECURITY.md` — responsible vulnerability reporting instructions.
- `SPONSORSHIP_README_SECTION.md` — section to append to the EXISTING README.md, not a replacement.

## Install

1. Download and extract the ZIP.
2. In your local clone of `Business-Analyst-Portfolio2`, copy the `.github` directory and the three community Markdown files into the repository root. Merge directories rather than replacing existing files without reviewing them.
3. Open `SPONSORSHIP_README_SECTION.md`, copy its contents, and append it to the end of your EXISTING `README.md` so none of your portfolio content is removed.
4. Review links and wording. Confirm that the GitHub Sponsors URL is accessible.
5. Commit and push the files to `main` (or use a pull request if you prefer).
6. In repository Settings > General, ensure Sponsorships is enabled if you want the Sponsor button displayed.
7. Check the repository homepage, issue creation page, and Sponsor button after the commit.

## Important notes

- Your account-level `.github` repository can provide default community files to repositories that do not contain their own. This ZIP targets the Business Analyst portfolio specifically.
- No existing README content is included or replaced because the complete current README was not supplied.
- The Code of Conduct intentionally does not invent a private contact email. Add a dedicated contact address later if you wish.
- Branch ruleset enforcement may depend on GitHub plan and repository settings.
