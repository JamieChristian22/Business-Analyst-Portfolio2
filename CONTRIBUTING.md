# Contributing

Thank you for your interest in improving this portfolio. Contributions that improve clarity, accessibility, documentation, examples, or reproducibility are welcome.

## Before contributing

- Review existing issues and pull requests to avoid duplicate work.
- For substantial changes, open an issue to discuss the proposed scope first.
- Do not include real client information, credentials, private data, or proprietary materials.
- Keep contributions aligned with the repository's business analysis, reporting, and process-improvement focus.

## How to contribute

1. Fork the repository and create a descriptive branch.
2. Make a focused change and document what you changed and why.
3. Verify that links work and that any sample data is synthetic or authorized for publication.
4. Open a pull request explaining the change, testing performed, and any relevant issue.

Maintainers review contributions as time permits. Submission does not guarantee acceptance.

## Reporting problems

Use the issue templates for bugs and enhancement ideas. For security concerns, follow SECURITY.md instead of opening a public issue.

## Community standards

By participating, you agree to follow the Code of Conduct.
