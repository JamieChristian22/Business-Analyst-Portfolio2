# Security Policy

## Supported scope

This repository is primarily an educational and professional portfolio. No formal support or patch-response SLA is promised.

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities, credentials, personal information, or other sensitive findings in public issues.

If GitHub's **Report a vulnerability** / private vulnerability reporting feature is enabled for this repository, use it. Otherwise, contact the maintainer privately through a contact method published on the GitHub profile. Include a concise description, affected files, reproduction steps, and potential impact. Do not share live secrets or personal data.

Reports will be reviewed as availability permits. No fixed remediation timeline or bounty is offered.
